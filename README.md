# csharp-jvm

A C# compiler that emits JVM bytecode instead of IL (Intermediate Language). This compiler allows you to write C# code and run it on the Java Virtual Machine.

```
┌─────────────┐      ┌────────┐      ┌────────┐      ┌──────────────┐      ┌──────────────┐
│  C# Source  │ ───> │ Lexer  │ ───> │ Parser │ ───> │ Code         │ ───> │ JVM Bytecode │
│    Code     │      │        │      │        │      │ Generator    │      │   (Jasmin)   │
└─────────────┘      └────────┘      └────────┘      └──────────────┘      └──────────────┘
                          │               │                  │                      │
                     Tokenizes       Builds AST        Generates               Runs on
                                                       Bytecode                  JVM
```

## Overview

This project implements a C# to JVM bytecode compiler that:
- Parses a subset of C# language syntax
- Generates JVM bytecode in Jasmin assembly format
- Supports basic language features including variables, arithmetic operations, and method calls

## Features

- **Lexical Analysis**: Tokenizes C# source code with support for comments
- **Syntax Parsing**: Builds an Abstract Syntax Tree (AST)
- **Code Generation**: Emits JVM bytecode in Jasmin format
- **Supported Language Features**:
  - Class and method definitions
  - Integer variables and arithmetic (`+`, `-`, `*`, `/`)
  - String literals
  - Method parameters
  - Return statements
  - Console output (`Console.WriteLine`)
  - Single-line (`//`) and multi-line (`/* */`) comments

## Prerequisites

- .NET 8.0 SDK or later
- Java JDK (to run the compiled bytecode)
- Jasmin assembler (optional, for converting to `.class` files)

## Building the Compiler

```bash
cd CSharpJvmCompiler
dotnet build
```

## Usage

```bash
dotnet run --project CSharpJvmCompiler <input.cs> [output.j]
```

### Example

```bash
dotnet run --project CSharpJvmCompiler examples/HelloWorld.cs
```

This will generate a `HelloWorld.j` file containing JVM bytecode in Jasmin assembly format.

## Running the Compiled Code

The compiler generates Jasmin assembly files (`.j`). To execute them:

1. **With Jasmin** (if you have it installed):
   ```bash
   jasmin examples/HelloWorld.j
   java HelloWorld
   ```

2. **Direct inspection**: The `.j` files are human-readable JVM assembly that show the generated bytecode.

## Generated Bytecode

The compiler generates JVM bytecode instructions such as:

- `iconst_*`, `bipush`, `sipush`: Load integer constants
- `iload`, `istore`: Load/store integer variables
- `iadd`, `isub`, `imul`, `idiv`: Arithmetic operations
- `invokevirtual`: Method invocation
- `getstatic`: Access static fields (e.g., System.out)
- `return`, `ireturn`: Return from methods

## Architecture

The compiler consists of several components:

1. **Lexer** (`Lexer.cs`): Converts source code into tokens
2. **Parser** (`Parser.cs`): Builds an Abstract Syntax Tree (AST)
3. **AST** (`Ast.cs`): Defines the structure of the syntax tree
4. **Code Generator** (`JvmBytecodeGenerator.cs`): Emits JVM bytecode from the AST

## Limitations

This is a minimal implementation demonstrating C# to JVM compilation. Current limitations include:

- Limited C# language support (no classes with fields, properties, etc.)
- Only basic types: `int`, `string`, `void`
- No control flow statements (if, while, for)
- No generics or advanced C# features
- Limited standard library support (only Console.WriteLine)
